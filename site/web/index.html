How it works

One request, start to finish.

The agent uses MCP tools, or the CLI with --json. The skill tells it to show you the price and ask before renting.

01

Ask

"Run this eval on Llama 8B." The agent writes gpu.yaml with gpu_init.

02

Price

gpu_offers lists matching GPUs under your cap. You say yes.

03

Serve

gpu_setup rents, boots vLLM and returns base_url, api_key, model. A stalled host is replaced.

04

Run, then stop

gpu_run runs the job. When requests stop, the watchdog stops the GPU.

Guardrails

Limits the agent can't talk its way past.

They live in gpu.yaml and on the machine, and they work the same with every provider. The agent would have to edit the file to raise them, and the skill tells it to ask you first.

15 min

Idle timeout

The watchdog on the machine shuts it down once requests stop. lifecycle.idle_timeout

$/h

Hourly and session budget

Offers above the cap are never rented, and a session that reaches its total stops. budget.max_hourly_cost_usd

6 h

Maximum lifetime

The machine stops at this age, busy or not. lifecycle.max_lifetime

10 min

Stalled hosts replaced

If the image download stops moving, gpu rents another host instead of waiting 30 minutes. health.pull_stall_timeout

sweep

Account sweep

gpu ls shows everything billing, and gpu sweep --install-timer cleans up machines no project owns.

gpu.yaml
gpu_runtime:
  provider: {name: vast}  # or your adapter
  model_profile: qwythos-9b
  lifecycle:
    idle_timeout: 15m   # watchdog shuts it down
    max_lifetime: 6h
  budget:
    max_hourly_cost_usd: 0.60
    max_session_cost_usd: 5.00
  health:
    pull_stall_timeout: 10m
Install

Paste one line into your agent.

The agent installs the gpu command, the Python it needs, the skill with the rules, and its tools. You connect your GPU provider in your own terminal, so the agent never sees the key.

  1. Paste this into Claude Code.

  2. When it asks, connect the account that pays for the GPUs. Type gpu login in your terminal app. It shows the providers you can use and walks you through it in about two minutes. Vast.ai works out of the box, and for a provider you already use, your agent adds it.
  3. Restart Claude Code and ask for an experiment. It shows the price and asks before renting anything.

        Any GPU provider
        
Use the provider you already pay for.

        
Vast.ai, RunPod and Lambda are built in: pick one in gpu login. For Paperspace, CoreWeave, your company's cluster or anything else with an API, your agent writes an adapter: one Python file that implements our provider contract. The watchdog, budgets, CLI and MCP tools work the same with every provider.

gpu_providers/paperspace.py


class PaperspaceProvider(GPUProvider):
    name = "paperspace"
    required_credentials = ["PAPERSPACE_API_KEY"]

    def find_offers(spec)   # GPUs that fit, cheapest first
    def setup(spec)         # rent one, run the boot script
    def status(instance)    # map states and ports
    def stop(instance)
    def destroy(instance)
    def list_instances()    # only jambu-* machines

# runs on the machine: shuts it down when idle
def provider_stop(ctx)
def provider_destroy(ctx)

          
gpu.yaml provider: {name: paperspace, plugin: ./gpu_providers/paperspace.py:PaperspaceProvider}
